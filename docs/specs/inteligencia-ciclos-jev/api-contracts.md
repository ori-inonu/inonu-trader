## Quotas, campos e interpretações importantes

- Nos 35 docs de OnchainOS do registry lidos, a maioria não publicou uma quota de requests. Não há número de requests/segundo dedutível dessas páginas. Seus limites de batch/página acima são somente os explicitamente escritos nos docs.
- Os 9 docs V5 vêm de um mirror oficial do projeto `okx/ai-builder-openapi-md` apontado no registry (`MIRROR`); quotas informadas acima são as textualmente publicadas e as regras de agrupamento são parte do limite.
- Documentação oficial pode divergir de implementação/naming: ex. docs de price-info indicam `volume5M` e `txs5M`, e source parsers precisam tratar campos efetivos de acordo com o contrato e os testes. Esta tabela descreve docs, não afirma compatibilidade validada em rede.
- Metadados do registry (tier/maxItems) são catálogo local; tiers marcados `unknown` permanecem desconhecidos e não foram convertidos em quota.

### Limites e incertezas

- Para as rotas `swap`/`approve`, as páginas foram lidas sem enviar request nem executar assinatura/broadcast; isso descreve apenas esta revisão documental, não toda a atividade histórica do sistema. Expiração/quota não publicadas.
- Agentic/TypeSafe AI: as páginas gerais previamente pesquisadas não publicaram RPM confirmado para o modelo; RPM permanece **desconhecido**. Esta revisão não invocou modelo.
- Escopo desta revisão: as 44 URLs do registry e os paths extras do source. Durante a leitura documental, nenhuma API foi chamada e nenhum contrato foi inferido de resposta live.

## Política local de dispatch OnchainOS (observação de runtime)

O transport DEX assinado em `src/onchain-read` aplica pacing local (`minIntervalMs` default de 1100 ms) e admite/registra uma unidade do budget local a cada invocação física de `fetch`, inclusive o único retry 50102 existente. O cap Basic/Premium vem de configuração local; cache hit e followers coalescidos não fazem dispatch nem consomem nova unidade. Prova com fetch sintético confirmou cap 0/1/2 e intervalo do retry; isso descreve exclusivamente implementação local, não quota publicada pelo fornecedor. Não generalizar para API pública V5, Agentic CLI/modelos ou outros tiers. Os rates oficiais não localizados continuam desconhecidos.
