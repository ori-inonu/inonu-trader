# g5: Os termos de uso integrais da OKX Web3 (secoes 2.7, 4.10 e 5.7, e o trecho a partir do caractere 100.000) e a OKX Web3 Build API Terms permitem coleta automatizada de paginas do OKX Wallet e do OnchainOS?

RESUMO: Os termos da OKX Web3 nao autorizam nem proibem expressamente a raspagem de paginas do OKX Wallet ou do OnchainOS. A "secao 4.10" citada no topico existe, mas com titulos diferentes em dois documentos: no Build API Terms e "Use of AI Agents" (agentes de IA e scripts automatizados), e no Wallet Software User Agreement e "Automated Pre-signed Transactions Risk". As secoes 2.7 e 5.7 nao foram encontradas nas versoes lidas. A clausula mais restritiva para dados de mercado esta na API Agreement, secao 9.4: proibe scripts, bots e raspadores para extrair Market Data em escala excessiva, inclusive em endpoints publicos sem autenticacao, e exige licenca de dados para acesso comercial de alto volume. Ausencia de clausula de scraping nao e permissao. Os trechos citados vieram de resumos do WebFetch, nao do texto bruto, e o trecho a partir do caractere 100.000 nao foi verificavel. A decisao final de risco de termos fica com o dono.
