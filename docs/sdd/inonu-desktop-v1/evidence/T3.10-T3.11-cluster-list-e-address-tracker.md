- **Validação antes de qualquer chamada:** `cluster-list` exige rede (só dígitos) e token (formato simples; um contrato que começa com `0x` numa rede EVM tem de ter `0x` e 40 hexadecimais, o que o ajudante compartilhado do catálogo não confere); `address-tracker-trades` aceita os três tipos de rastreio, exige de 1 a 20 endereços só no tipo 3 (EVM em minúsculas, Solana como está, sem repetição) e recusa endereços nos outros tipos, o tipo de negócio de 0 a 2, as cinco redes da página (501, 1, 56, 8453, 196) e os sete filtros como decimais sem sinal nem expoente.
- **Saída para o navegador:** carteiras de terceiros encurtadas (`B6NR...mQbQ`), no máximo 5 por grupo; números ilegíveis são `null`, nunca zero; um grupo ou negócio sem o que é indispensável é descartado e os outros ficam; lista vazia é resposta vazia, e um formato fora do documentado é erro de contrato (nunca um token "sem grupos"). `normalizeInternal` entrega as carteiras inteiras só ao processo do servidor (SMT-4), como `signals` e `holders`.
- **A documentação se contradiz** e as duas grafias são lidas: a tabela diz `clustList`, o exemplo diz `clusterList`, dentro de um objeto (e não de uma lista).
- **Testes:** `clusters-detail.test.ts` (15) e `address-tracker.test.ts` (15) com o exemplo documentado de cada página (rótulo `documented_example`), mais a lista fixa de rotas de `catalog.test.ts` (82). Gateway, núcleo e entrada desktop (`src/onchain-read`, `src/inonu`, `src/desktop`): 841 passam, 0 falham; `bun run typecheck` limpo.

**A-08 respondido para esta chave: a família `address-tracker/trades` está habilitada.** O que a leitura mostrou e a documentação não dizia:

- `lastActiveTimestamp` de `cluster/list` vem em **segundos** (1791912423, de seis horas antes), e `tradeTime` do rastreador vem em **milissegundos**. O gateway converte o primeiro para milissegundos.
- `holdingPercent` é uma **fração** (0,10284 para um grupo com 10,28% da oferta de BONK) e `averageHoldingPeriod` é um **momento em segundos** (1768447365 é janeiro de 2026), não uma duração. Os dois seguem como o provedor os escreve, com a leitura registrada no cabeçalho do arquivo.
