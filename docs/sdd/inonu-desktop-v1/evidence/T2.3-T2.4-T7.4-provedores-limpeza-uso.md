## Como usar a limpeza (só quando o usuário decidir)

```
bun --no-env-file run scripts/provision.ts --cleanup            # o plano: o que sairia, sem escrever nada
bun --no-env-file run scripts/provision.ts --cleanup --yes      # faz, depois de gravar o backup
bun --no-env-file run scripts/provision.ts --restore <backup>   # devolve as linhas
```

O backup (`data/backups/`, fora do git) guarda os mesmos valores em texto puro: apagar quando o app funcionar sem os arquivos.
