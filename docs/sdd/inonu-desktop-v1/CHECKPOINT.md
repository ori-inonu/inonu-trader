## Lições deste trabalho

0. Comandos: `bun run build:desktop` (instalador em `dist/desktop`), `bun run desktop:smoke` (instala em pasta temporária, confere e desinstala), `bun run desktop:provision -- --dry-run` (importa as chaves do `.env` para o cofre; sem `--dry-run` grava; nunca imprime valor).

Não editar as bibliotecas OKX (`src/okx-api.ts`, `src/okx-market/*`, `src/okx-wallet/*`, `src/okx-signals/client.ts`) nem `scripts/onchainos-capture.ts`: os testes de isolamento do projeto (`src/pilot/isolation.test.ts`, `src/onchainos/isolation.test.ts`, `src/okx-market/okx-cli.test.ts`) proíbem importar o módulo de relógio (faz rede). 2. O `bun run test` completo tem folga de temporizador sensível a carga neste repositório; rodar sozinho antes de acusar regressão.
3. `.env` desta máquina contém `PRIVATE_KEY` e `LIVE_ACK` do trader Kuru: o provisionamento só lê os 4 nomes do cofre e trata `${NOME}` como marcador, não como chave.
