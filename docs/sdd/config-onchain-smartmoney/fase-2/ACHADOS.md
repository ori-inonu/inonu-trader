# Registro de achados (2026-10-12 e 2026-10-13)

Cada linha é um fato com tipo e evidência. **Medido ao vivo** quer dizer que a sonda real, com a chave do projeto e plano Trial, observou o fato. **Documentado** é o que a página pública diz. **Lido no código** é leitura do repositório. **Inferido** e **não verificado** são hipóteses e ficam rotuladas. Evidência em `evidence/` desta pasta foi saneada: forma e código, nunca valores de dados (exceto [escalas-percentuais](evidence/escalas-percentuais-2026-10-12.json), que guarda poucos valores públicos de métricas de token para decidir escalas). Quem consome o achado está na última coluna (`F2-*` é requisito da [SPEC](SPEC.md), `D3-*` é delta do [adendo](ADENDO-REV3.md)).
